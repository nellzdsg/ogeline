# ОГЭлайн

Бесплатный статический тренажёр для подготовки к ОГЭ. Задания берутся из
открытого банка заданий ФИПИ, ответы проверены, к каждому заданию есть подсказки
и разбор.

## Что уже работает

- **Математика** — 863 задания: все с подтверждённым ответом, подсказками и разбором.
  Они разложены по номерам, как в варианте ОГЭ: № 6 «Числа и вычисления» (132),
  № 7 «Числа на координатной прямой» (77), № 8 и 12 «Выражения и расчёты по формулам»
  (446), № 9 «Уравнения» (99), № 13 «Неравенства» (109).
- **Стартовое меню**: что это за сервис, как пользоваться и выбор предмета. Показаны все
  14 предметов ОГЭ; задания наполняются постепенно.
- **Навигация по номерам заданий**, а не по кодам КЭС: выбираете номер — получаете все
  задания этого номера из банка ФИПИ. Для номеров 1–5 (практические задачи) задания
  дополнительно разбиты по сюжетам: шины, квартира, план участка и другие.
- **Светлая и тёмная темы**: по умолчанию как в системе, переключатель — в шапке.
- Все ответы **подтверждены** у ФИПИ (не угаданы): у банка есть проверка «верно/неверно»,
  которой мы пользуемся как оракулом.
- У каждого задания — три подсказки по возрастанию подробности и пошаговый разбор.
- Прогресс хранится в браузере (`localStorage`) и никуда не отправляется.
- Сайт полностью статический: без сервера, без внешних библиотек, формулы рисует
  сам браузер (MathML), поэтому всё работает бесплатно на любом статическом хостинге.

## Структура

```
tools/crawler/    обход банка ФИПИ и определение ответов
  lib/http.mjs      сеть, сессия, «оракул» проверки ответа
  lib/parse.mjs     разбор страниц банка
  lib/html.mjs      подготовка условия (картинки, MathML, чистка)
  lib/mathml.mjs    перевод MathML в вычисляемое выражение
  lib/solvers.mjs   вычисление ответов для кратких ответов
  crawl.mjs         загрузка заданий
  harvest-answers.mjs  определение и проверка ответов
tools/build/      сборка сайта
  numbers.mjs       сопоставление заданий банка номерам ОГЭ (по спецификации ФИПИ)
  expr.mjs          расчёт и пошаговое решение «вычислить выражение»
  prototypes.mjs    разбор по прототипам: подсказки и решения
  build-site.mjs    data/** -> web/data/*.json + web/media
  serve.mjs         локальный предпросмотр
web/              сам сайт (index.html, app.js, styles.css)
data/math/        собранные задания (tasks.ndjson) и картинки
```

В открытом банке задания подписаны кодами КЭС, а не номерами позиций КИМ. Соответствие
«код КЭС → номер задания» задано в `tools/build/numbers.mjs` по спецификации ОГЭ (ФИПИ).


## Команды

```bash
npm run crawl   -- --subject math --theme 1 --rounds 3   # загрузить задания
npm run harvest -- --subject math --kinds choice,short   # определить ответы
npm run build                                            # собрать сайт
npm run serve                                            # открыть http://localhost:5173
```

## Как получаются ответы

ФИПИ не публикует правильные ответы. Но страница проверки отвечает «верно/неверно»
на любой введённый ответ. Поэтому:

- для заданий с выбором ответа правильный вариант находится перебором;
- для заданий с кратким ответом ответ **вычисляется**, а затем подтверждается у ФИПИ;
- если ответ не подтверждён — задание остаётся без ответа и в базу не попадает.

Такой подход исключает неверные ответы: на сайте появляются только проверенные.
